# Развертывание

Целевая инфраструктура: VPS (reg ru или аналог) — минимум 2 vCPU, 4 ГБ RAM, 20 ГБ SSD.

## Шаги

1. Установить Python 3.11+.
2. Создать виртуальное окружение и установить зависимости.
3. Задать переменные окружения:
   - `TELEGRAM_BOT_TOKEN`
   - `KAD_API_BASE_URL`
   - `KAD_API_KEY`
   - `ADMIN_AUTH_TOKEN`
   - `HASH_SALT`
   - `DATABASE_PATH` (опционально, по умолчанию `data/app.db`)
4. Настроить systemd сервисы:
   - `bot.service`
   - `admin.service`
5. Настроить логирование (stdout + ротация).

## Мониторинг

- Проверка доступности по `/health`.
- SLA: 95% в рабочие часы (Пн-Пт, 9:00-18:00 МСК).
