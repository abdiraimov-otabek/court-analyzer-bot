# Админка

## Цели

- Управление доступом пользователей к боту.
- Настройка глубины поиска (сколько дел и документов по делу анализировать).
- Просмотр/редактирование промпта анализа.

## Функции

1. **Глубина поиска**
   - `max_cases` — максимальное число дел для анализа (по умолчанию 500, допустимо 5-500).
   - `max_documents_per_case` — сколько актов/документов анализировать внутри дела.
   - `max_pages` — ограничение на пагинацию при запросах.
   - `fetch_concurrency_min` — нижняя граница параллельной загрузки деталей дел.
   - `fetch_concurrency_max` — верхняя граница параллельной загрузки деталей дел.
   - `slow_alert_minutes` — через сколько минут отправлять пользователю уведомление, что анализ продолжается.
   - `details_cache_ttl_seconds` — TTL кэша деталей дел (`CaseId`) в секундах.

2. **Доступ к системе**
   - Список разрешенных Telegram ID.
   - Доступ только по whitelist.

3. **Промпт анализа**
   - Хранится как текстовая настройка.
   - Доступен для просмотра и редактирования в админке.

## Рекомендуемая реализация

- Admin API на FastAPI.
- Аутентификация: Bearer-токен из переменной окружения `ADMIN_AUTH_TOKEN`.
- UI: минимальная панель (можно начать с API и подключить легкий фронтенд позже).

## Минимальная панель

- URL: `/admin?token=<ADMIN_AUTH_TOKEN>`
- Функции: настройки глубины, список пользователей, редактирование промпта.
