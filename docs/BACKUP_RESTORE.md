# Резервное копирование и восстановление

## База данных

Рекомендуется использовать SQLite для MVP.

### Бэкап

- Остановить сервисы (или выполнить backup в режиме read-only).
- Скопировать файл базы данных `data/app.db`.
- Хранить минимум 7 последних бэкапов.

### Восстановление

- Остановить сервисы.
- Заменить файл базы данных на актуальный backup.
- Запустить сервисы и проверить `/health`.
